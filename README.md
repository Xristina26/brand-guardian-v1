# 🛡️ Brand Guardian

One central engine for internal ops, tech, and marketing. Stop hunting for PDFs—get a definitive **Yes/No** on every asset instantly.

## 🚀 Overview

Brand Guardian is a high-fidelity audit tool designed for cross-sector organizations (Startups, Fintech, Edtech, Martech, etc.) to ensure absolute brand consistency across all departments.

### Key Features:
- **Universal Audit Engine**: One tool for all teams—Marketing, Ops, Tech, and Product.
- **Multi-Document Support**: Supports PDF, Word (.docx), PowerPoint (.pptx), and plain text.
- **Yes/No Compliance**: Instant feedback on whether content aligns with the provided guidelines.
- **Local Persistence**: Guidelines and review history are saved securely to your browser (localStorage).
- **Portfolio-Ready**: Includes a simulated "Demo Mode" for demonstration purposes when an API key is not present.

## 🛠️ Technical Stack
- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **AI Engine**: [Google Gemini Pro](https://deepmind.google/technologies/gemini/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Xristina26/brand-guardian.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up Environment Variables**:
   Create a `.env` file in the root and add your Gemini API key:
   ```env
   VITE_GEMINI_API_KEY=your_api_key_here
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```
